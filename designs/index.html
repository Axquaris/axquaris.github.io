Redesign candidates

Five light-mode directions for the homepage. Each is a single self-contained HTML file with its CSS in a <style> block and the same content, so they can be compared directly and the winner folded back into index.html plus stylesheet.css.

  1. 01Lattice

    Swiss grid. Hairline rules, a monospace metadata rail down the left, no cards and no shadows. The quietest option and the closest relative of the current site.

  2. 02Atelier

    Soft white panels on a tinted ground, headshot, pill links, publication rows as cards. The most conventional academic homepage, in the vein of the Jiahui Lei reference.

  3. 03Orbit

    Graphic poster. Arch, colour blocking in chartreuse on forest, wide monospace micro-typography and a numbered index of work. The boldest of the five.

  4. 04Preprint

    The page set as a typeset paper. Monospace throughout, numbered sections, running head, figure captions and a bibliography-style list with Garamond titles.

  5. 05Manifold

    Editorial. A didone display face, violet accents, a two-column grid of work and a canvas-generated rosette with six-fold symmetry in the hero.
